## Pravni MCP Server za Bosnu i Hercegovinu (`ba-legal-mcp`) — Bosanski

### O ovom repozitoriju

Ovaj repozitorij sadrži Model Context Protocol (MCP) server koji povezuje vašu AI aplikaciju (Claude Desktop, Cursor, Windsurf, VS Code / Copilot, Cline ili Antigravity) direktno sa službenim glasnicima i bazama sudskih odluka u **Bosni i Hercegovini** (općinski i osnovni sudovi, svih 10 kantonalnih sudova u FBiH, 6 okružnih sudova u RS, Apelacioni sud Brčko distrikta BiH, vrhovni sudovi entiteta, Sud BiH i Ustavni sud BiH).

### Brza instalacija (Izbor AI aplikacije)

1. **Preuzimanje:** Kliknite na dugme **`<> Code`** u gornjem desnom uglu i odaberite **`Download ZIP`**, a zatim raspakujte fasciklu na računaru.
2. **Pokretanje instalacije:** Pokrenite **`Click_Here_To_Install_Windows.bat`** (Windows) ili **`Click_Here_To_Install_Mac.command`** (macOS).
3. **Odabir AI aplikacije:** U prozoru za instalaciju označite koje AI programe koristite (Claude, Cursor, Windsurf, VS Code, Antigravity), kliknite na dugme za instalaciju i ponovo pokrenite odabranu AI aplikaciju.

**Sigurnosna napomena:** Instalacija radi isključivo u režimu čitanja (read-only) i nema pristup vašim ličnim datotekama ili dokumentima na računaru.

## English Documentation

Model Context Protocol (MCP) server providing live, read-only access to **Bosnia and Herzegovina (BA)** legislation, official gazettes, multi-tier judicial decisions (First Instance, Regional/Cantonal/Appellate, and Supreme/Constitutional courts, including HTML and PDF full-text extraction), and statutory citation verification across all major AI clients (**ChatGPT Desktop, OpenAI Codex CLI, Claude Desktop, Claude Code CLI, Cursor, Windsurf, VS Code / GitHub Copilot / Cline / Roo Code, Google Antigravity / Gemini CLI, Perplexity, and Continue.dev**).

---

### Interactive Desktop Setup (Select Your AI Assistant)

This package includes a graphical installer for legal practitioners and non-technical users that lets you select which AI application(s) you use:

1. **Download:** Click **`<> Code`** at the top right of this repository, select **`Download ZIP`**, and extract the folder to your computer.
2. **Run the Setup Utility:**
   - **Windows:** Double-click `Click_Here_To_Install_Windows.bat`
   - **macOS:** Double-click `Click_Here_To_Install_Mac.command`
3. **Select Your AI Client(s) & Connect:** Check the box(es) for the AI assistant(s) installed on your computer (**ChatGPT Desktop & OpenAI Codex CLI**, **Claude Desktop & Claude Code CLI**, **Cursor**, **Windsurf**, **VS Code / GitHub Copilot / Cline / Roo Code**, **Google Antigravity / Gemini CLI**, or **Perplexity / Continue.dev**), click **Install to Selected AI Clients**, and restart your selected AI application.

**System Integrity Note:** The setup utility operates strictly in read-only mode with respect to your personal files and documents. It installs an isolated Python runtime inside the extracted folder and registers the server entry only in the AI client configuration files you select.

### Available MCP Tools

| Tool | Description |
|:---|:---|
| `search_legislation` | Searches enacted statutes, codes, decrees, and official gazette publications in Bosnia and Herzegovina. |
| `search_case_law` | Searches national jurisprudence and open judicial archives for Bosnia and Herzegovina. |
| `search_tiered_court_decisions` | Filters case law specifically by judicial instance (`first_instance`, `appellate_regional`, `supreme_constitutional`) or specific regional/cantonal/district court. |
| `list_court_hierarchy` | Returns the complete 3-tier court structure and supported regional court filters for Bosnia and Herzegovina. |
| `get_legal_document_markdown` | Retrieves full statutory or judicial texts (both HTML and official `.pdf` court judgments) and converts them into clean Markdown. |
| `verify_citation` | Validates statutory and case law citations against official registries. |
